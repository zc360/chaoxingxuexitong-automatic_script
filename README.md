## 如何使用

1. 在 Edge / Chrome 安装官方扩展商店中的 Tampermonkey（篡改猴）。
2. 打开[Greasyfork地址](https://greasyfork.org/zh-CN/scripts/607395-%E5%AD%A6%E4%B9%A0%E9%80%9A-%E5%A4%9A%E8%A7%86%E9%A2%91%E5%A4%9A%E7%AA%97%E5%8F%A3%E5%90%8C%E6%97%B6%E6%92%AD%E6%94%BE%E4%B8%8E%E5%8E%BB%E9%99%A4%E9%BC%A0%E6%A0%87%E7%A7%BB%E5%87%BA%E6%A3%80%E6%B5%8B)，点击安装。
3. 回到课程页面刷新一次，可打开设置页面调节功能开关。
4. 若扩展提示需要“允许用户脚本”，按 Tampermonkey 的提示开启，并允许扩展访问超星课程页面。

## 功能与行为（可调节功能开关）

- 学习通多视频同时播放
- 切到后台保持播放
- 去除鼠标移出检测
- 新视频自动静音
- 自动播放下一视频（需手动设置自动”点击下一节“次数）

## 注意事项

- 多视频播放功能仅适用于同一标签页内多个视频和多个窗口不同标签页，不能同一窗口多标签页播放
